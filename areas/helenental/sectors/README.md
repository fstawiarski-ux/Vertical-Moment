# Höllental sector catalogue

Each folder is a lightweight staging manifest. `route_count_v1` combines sport
and boulder records that Master V1 stores under separate wall labels. It is a
matching inventory, not a published topo.

The first four folders are the active 3D/topo pilot. The remaining Master V1
sectors await the corresponding Keltenkalk topo/list source. Badener
Kletterschule is included as a named source-intake location even though it has
no matching Master V1 route records yet.

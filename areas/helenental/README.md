# Höllental / Helenental

This directory holds the area-specific working material for Höllental (also
spelled Helenental in older source files). It does not replace the canonical
route master in `database/generated/routes_v1.json`.

## Active pilot

The first four-wall pilot is deliberately small enough to establish a reliable
repeatable method before the rest of the area is promoted. The wider Höllental
catalogue is now staged under `sectors/` from Master V1, with each non-pilot
wall awaiting its Keltenkalk source package.

- Beethovenwand
- Engelstein
- Siegenfelder Steinbruch
- Jammerwandl

The pilot is in **input collection**. The route inventory is derived from
Master V1 for comparison only; it becomes publishable only after its topo and
field checks are recorded.

See [`pilot/README.md`](pilot/README.md) for the process and
[`pilot/INPUTS_NEEDED.md`](pilot/INPUTS_NEEDED.md) for the upload checklist.

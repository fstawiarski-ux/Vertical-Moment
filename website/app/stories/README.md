# Story photo updates

The three story pages read their photo and caption details from story-content.ts in this folder.

When the final photo sets are ready:

1. Export approved web copies as optimized WebP or AVIF files. Keep the CR2 masters outside the website.
2. Put each format's images in website/public/photography/stories/climbing, product or events.
3. In story-content.ts, update coverImage and the matching chapters' imageSrc and imageAlt values.
4. Update chapter titles, captions and notes to match the confirmed story.
5. Review the local pages on desktop and mobile before publishing.

The current pages use photographs already in the public portfolio as temporary samples.

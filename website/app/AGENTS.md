# Next route ownership rules

This route tree is transitional and contains both products.

Default public-site ownership applies to `page.tsx`, photography home styling and `components/photography-*`.

Climbers Lounge/PWA ownership applies to:

- `explore-app/`
- `(platform)/explore/`
- `(platform)/contribute/`
- `(platform)/report/`
- `climbers-lounge/`
- `offline/`
- `nasenwand-concepts/`
- `components/nasenwand/`
- climbing panorama/topo/3D/spatial routes

The contributor beta stores original evidence on the device and exports review ZIPs. It does not upload to a server or publish data automatically.

Root layout, global CSS, not-found handling and sitemap behavior can affect both products. Declare shared impact before editing them. Consult `docs/PRODUCT_MAP.md` when a path is ambiguous.

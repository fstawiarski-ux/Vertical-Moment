# Climbers Lounge / Explore PWA source rules

This tree belongs to the `climbers-lounge-pwa` product.

Preserve desktop freeform layout, tablet grid, phone cards, collision avoidance, persisted layout, lazy heavy content and offline capability. Extend existing surfaces rather than creating parallel global controls.

Do not statically import large Atlas JSON into initial startup. Do not invent route/sector data or deep-link behavior. Keep the Command Palette, layout state and PWA services within their established ownership boundaries.

Public-site visual work must not edit this tree. Shared package or deployment changes require cross-product approval.

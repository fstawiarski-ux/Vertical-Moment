# Vertical Moment official identity v2.0

These are the reviewed web derivatives from `Vertical_Moment_Official_Identity_Master_Bundle_v2.0.zip`.

## Runtime roles

- `marks/forest-green-vm.webp`: default public identity.
- `marks/brushed-dark-silver-vm.webp`: technical and neutral identity.
- `marks/iridescent-vm.webp`: digital motion and loading identity.
- `marks/gold-c-frame-cvm.webp`: Collective and premium identity.
- `utility/`: high-contrast small-size marks.
- `icons/`: install, Apple and favicon derivatives.
- `watermarks/`: white video-overlay constructions.

Do not add the source EPS/PDF files, editable masters or raw production media to this public directory. Do not recreate or recolour these assets in CSS.

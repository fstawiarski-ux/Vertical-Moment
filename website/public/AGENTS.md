# Public asset rules

This directory contains assets for both products.

- Classify each asset as public-site, PWA, shared, generated or provisional before changing it.
- `sw.js` is generated and must never be hand-edited or included in a source patch.
- `explore-content.json`, the PWA manifest/icons, Atlas GPX and Explore/Nasenwand media belong to the PWA stream unless the product map says otherwise.
- Brand and photography assets may be shared; preserve source ownership, rights, dimensions and checksums.
- Do not add raw scans, source photo sets or oversized reconstruction outputs. Use approved optimized derivatives or external versioned storage.

# Brand assets

## Canonical logo

Use `canonical/svg/vm-monogram.svg` whenever the target supports SVG. It is the primary Vertical Moment monogram. The matching transparent PNG exports are provided for platforms that require raster images:

- `vm-monogram-ink.png` — default light-background mark
- `vm-monogram-white.png` — dark-background mark
- `vm-monogram-forest.png` — forest-green brand context
- `vm-monogram-terracotta.png` — terracotta brand context

Do not create new logo variants by editing the PNG files. Update an Affinity source, export a reviewed replacement, then update this directory through a pull request.

## Source and motion files

- `source-affinity/` retains the editable Affinity files and the received vector archive. These files use Git LFS.
- `motion-drafts/` contains draft MP4 logo animations. They are not approved social or website assets until a final name, size, background treatment and usage are selected.
- `reference-exploration/` retains one contact sheet documenting the prior visual exploration. It is reference-only; it is not a logo library.

## Usage rules

Keep clear space around the monogram, preserve its proportions, and use the SVG/approved PNGs rather than screenshots or generated derivatives. Do not use assets carrying AI-generator watermarks or unfinished experimental marks in public work.

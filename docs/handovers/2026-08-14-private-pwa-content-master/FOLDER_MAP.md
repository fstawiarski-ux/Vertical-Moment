# Content intake and repository map

## Private owner intake root

Upload or copy new material here first:

```text
D:\VERTICALMOMENT\WEBSITE\private-assets\vm-content-intake\
```

This root is intentionally outside the Git repository and must not be deployed or committed. Its folders are:

```text
00-INBOX\                 raw owner uploads; never edit in place
01-SOURCE-REVIEW\         immutable copy, checksums, rights and provenance
02-DERIVATIVES\           approved AVIF/WebP/MP4/GLB derivatives under review
03-CONTENT-REGISTRY\     record JSON, stable IDs, captions and link targets
04-REVIEW-PACKAGES\      screenshots, device checks, manifests and decisions
05-APPROVED-FOR-PUBLISH\ exact approved files staged for a repository change
06-ARCHIVE\               superseded packages; preserve, do not overwrite
README.md                 owner instructions and status legend
```

The owner can drop material into `00-INBOX` without knowing the final page. The next agent moves a copy through the workflow only after preserving the original name, date, source, rights state, and checksum. “Move” here means a reviewed copy in the workflow; the original master stays intact.

## Repository destinations

| Content | Repository destination | Source rule |
| --- | --- | --- |
| PWA box registry | `website/public/explore-content.json` | Stable IDs; update references and PWA cache revision together. |
| Canonical regions, crags, routes | `database/master/` and generated `database/api/v1/` | Canonical/reconciled data first. Never edit the website mirror as source. |
| Generated browser data | `website/public/data/v1/` | Generated by `npm run sync-data`; do not hand-edit. |
| PWA images and posters | `website/public/photography/explore-app/` | Derivatives only; keep masters in private intake. |
| Public photography | `website/public/photography/` | Add only when separately approved for public website use. |
| Panorama previews/manifests | Existing panorama/PWA media folders | Use the shared viewer and preserve region/crag/sector links. |
| Optimized 3D | `website/public/models/` | Review GLB size, loading, fallback poster, and provisional label. |
| Scrub videos | `website/public/photography/explore-app/scrub/` | Optimized derivatives only; preserve actual duration and direction. |
| GPX/PDF evidence | Private intake or explicitly approved delivery folder | Never imply that a file is canonical without source review. |

## Naming pattern

Use stable semantic names with an immutable content ID or hash, for example:

```text
vm-wachau-nasenwand-upper-context-<content-id>-960.avif
vm-wachau-nasenwand-upper-panorama-<content-id>-1600.webp
vm-wachau-nasenwand-upper-poster-<content-id>-960.webp
```

Do not rename a published ID because a caption changes. Add a new revision field or derivative while keeping the content ID stable.
